What is this?

Eat Well AI is a natural-language restaurant finder for people with dietary needs: vegan, vegetarian, gluten-free, kosher, and halal. Demo's friend Miriam keeps kosher and has trouble finding places to eat. Demo is vegan, and they eat out together often.

Type what you want in plain English ("vegan pizza in Chicago", "kosher in Miami") and the app searches 1,017 restaurants across 37 cities.

How the AI search works

The AI runs entirely in your browser. No server, no API key, nothing leaves your device.

  • Model: Qwen3-0.6B, Alibaba's open-source model (Apache 2.0), running via WebLLM with WebGPU.
  • First load: downloads ~400MB once, then works offline.
  • Browser: you need Chrome or Edge with WebGPU for the AI search. The restaurant list works everywhere.
  • Pipeline: your query goes to Qwen with a system prompt that shapes its answer into a JSON filter object, {diets, city, keywords}. Plain JavaScript applies those filters to the local database.

The data

1,017 restaurants across 37 cities (14 US, 5 Canadian, 5 UK, 13 additional US), each tagged for vegan, vegetarian, gluten-free, kosher, and halal options. Listings link to MapQuest, with QR codes for the badge companion. HappyCow links appear where verified.

Menus change. Verify dietary needs directly with the restaurant. Listings were researched in October 2026.

Run it locally

Static site. Serve the folder, open it in Chrome or Edge:

python3 -m http.server 8000
# then open http://localhost:8000

Source: github.com/Mike-Demo/eat-well-ai (MIT).

Admin: add your own listings

The app has a small admin panel for adding custom listings. Your browser stores them in localStorage:

  • Open the admin login page and enter the admin password.
  • Add manually: name, city, cuisine, price, diets, notes.
  • Upload CSV with columns name,city,cuisine,price,diets,area,note,rating,map_url. Separate diets with ;. Grab the sample CSV for the format.
  • My listings: review and remove anything you added.

The password gate is demo-grade. It ships in the site's JavaScript, so it keeps honest visitors out without real security.
